# Coffee Shops Tia Rosa

Sistema de gerenciamento de cafeteria desenvolvido em Python para uma atividade acadêmica.

## Funcionalidades

- Cadastro e consulta de produtos;
- Cardápio com ingredientes, preços e promoções;
- Cadastro e consulta de clientes;
- Realização de pedidos;
- Controle automático de estoque;
- Programa de pontos: 1 ponto a cada R$ 10,00 gastos;
- Consulta de pedidos;
- Relatório de vendas e estoque baixo;
- Salvamento automático dos dados em JSON.

## Tecnologias e conceitos utilizados

- Python 3;
- Classes e objetos;
- Listas e dicionários;
- Funções e métodos;
- Estruturas condicionais e de repetição;
- Tratamento de erros;
- Leitura e gravação de arquivo JSON.

## Como executar

1. Instale o Python 3.
2. Coloque o arquivo `coffee_shops_tia_rosa.py` em uma pasta.
3. Abra o terminal nessa pasta.
4. Execute:

```bash
python coffee_shops_tia_rosa.py
```

No Windows, também pode ser necessário usar:

```bash
py coffee_shops_tia_rosa.py
```

O arquivo `dados_cafeteria.json` será criado automaticamente na primeira execução.
